# マレットゴルフ スコア表 Ver.2.0（正式版）

## 主な機能
- 4～7人対応
- 5～7人は横画面で画面内表示
- 内回り：1～9ホール
- 外回り：10～18ホール
- 外回りの下に18ホール総合計を表示
- 総合計は薄い黄色・太字・大きめ表示
- 入力後、自動で次の人へ移動
- 次の入力セルを赤枠表示
- 「全員3」「全員4」ボタン
- バーディー赤、イーグル以下青
- 入力済みセルはクリーム色
- 印刷対応
- iPhone・Androidのホーム画面追加対応
